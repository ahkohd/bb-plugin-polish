# Polish

A clean, minimal theme plugin for bb on [Flexoki](https://stephango.com/flexoki),
Steph Ango's inky palette for reading and writing.

- Ink on paper, hairline borders, no decorative shadows, small radii.
- One sparing accent (Flexoki orange) for the selected thread.
- Plain tables, outlined inline code, quiet links, a flat composer.
- Code blocks use the Flexoki VS Code themes (MIT, see
  `themes/code/FLEXOKI-LICENSE`).

Turn it on in Settings, Appearance, or run `bb theme set plugin:polish:polish`.
Switch back with `bb theme reset`.
