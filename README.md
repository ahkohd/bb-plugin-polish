# Polish

A clean, minimal theme plugin for bb in the style of [Capy](https://capy.ai).

- Neutral cool greys: a grey sidebar beside a near-white main area.
- Hairline borders, no decorative shadows, 6px radii.
- Inter at weight 450, as in Capy's app.
- One blue accent for primary actions, counts and links.
- Plain tables, quiet inline code, a white composer card.
- The sidebar footer's warning and update pills are hidden. Plugin errors,
  machine issues and updates stay in Settings.
- Code blocks use the Flexoki VS Code themes (MIT, see
  `themes/code/FLEXOKI-LICENSE`).

Turn it on in Settings, Appearance, or run `bb theme set plugin:polish:polish`.
Switch back with `bb theme reset`.
